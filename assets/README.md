> The junk drawer. Except the junk is diagrams, screenshots, and the occasional cursed meme that explained a bug better than any stack trace.

## What belongs here

- 📸 Screenshots that prove something actually happened
- 📊 Diagrams that made a concept click (for me, if no one else)
- 🎨 Images referenced by experiments or notes
- 🧵 Anything visual that doesn't belong in code but belongs in the story

## Rules to keep entropy from winning completely

1. If an image belongs to *one* experiment, it lives in that experiment's own folder instead — keep this one for shared or general-purpose stuff.
2. Compress before you commit. Git does not forgive large binaries.
3. Name things like a human, not like a screenshot default:
   - ✅ `websocket-storm-graph.png`
   - ❌ `Screenshot 2026-09-24 at 3.47.12 AM.png`
