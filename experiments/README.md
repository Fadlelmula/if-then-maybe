## What you'll find

Each subfolder is one question I got curious enough about to actually write code for, instead of just wondering about it in the shower.

```

```

## The rules of this lab

1. 🔬 **Small.** If it needs a `README` longer than this one, it graduates to `prototypes/`.
2. 💥 **Disposable.** Delete-ability is a feature, not a bug.
3. 📓 **Documented enough to laugh at later.** Future-me deserves context, not archaeology.
4. 🚫 **No production code allowed.** This is a sandbox, not a load-bearing wall.

## Folder naming convention

```
YYYY-MM-DD_short-description-of-the-crime/
```

Each one gets a mini `README.md` with:
- what I was testing
- what actually happened
- what I'd try next (or why I gave up, gracefully)
